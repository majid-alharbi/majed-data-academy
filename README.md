# MAJED DATA ACADEMY

منصة تعليمية عربية مجانية لمقرر **إدارة بيانات الأعمال**، مبنية على «ملخص مبسط لإدارة بيانات الأعمال» (الفصول 1–5)، وتعمل بالكامل داخل المتصفح على GitHub Pages.

> افهم ← شاهد ← جرّب ← طبّق ← اختبر ← صحّح ← راجع

## ما الموجود في النسخة 0.1

| الجزء | الحالة |
|---|---|
| الرئيسية، الفصول، عارض الدروس، المختبرات، بنك الأسئلة، محاكي الاختبار، لوحة التقدم | تعمل |
| 6 فصول (5 من الملخص + المراجعة السريعة)، 17 درسًا بالمراحل السبع | تعمل |
| زرا «اشرحها أبسط» و «مخي قفل» (خلاصة + مثال واحد، أو استراحة 5 دقائق) | تعمل |
| مختبر الجبر العلائقي: σ π ρ ∪ ∩ − × ⋈ مع خطوات وسيطة وKaTeX | يعمل |
| مختبر SQL: Monaco + SQLite داخل المتصفح + 15 تمرينًا مصححًا | يعمل |
| مختبر ERD (رسم Chen بـ React Flow) والتحويل إلى نموذج علائقي | يعمل |
| مختبر التطبيع: الإغلاق، المفاتيح المرشحة، 2NF/3NF/BCNF، تفكيك 3NF | يعمل |
| بنك أسئلة: 130 سؤالًا (8 أنواع) | يعمل |
| حفظ التقدم محليًا (localStorage) دون أي خادم | يعمل |

## التشغيل محليًا

```bash
npm ci
npm run dev        # http://localhost:5173/majed-data-academy/
npm test           # اختبارات المحركات والمحتوى
npm run build      # فحص الأنواع + بناء الإنتاج في dist/
```

## النشر

كل دفع إلى `main` يشغّل `.github/workflows/deploy.yml`: تثبيت ← فحص TypeScript ← الاختبارات ← البناء ← النشر على GitHub Pages. لا يُنشر شيء إذا فشلت أي خطوة.

الرابط بعد النشر: `https://<GitHub-username>.github.io/majed-data-academy/`

للنشر أول مرة من هذا الجهاز: `scripts/publish.ps1` (يتطلب GitHub CLI مسجل الدخول).

## ملاحظات علمية

- **علاقة 1:1**: ورد في الملخص «مفتاح أجنبي في جدول الطرف الاختياري». المنصة تعتمد القاعدة المرجعية (Elmasri & Navathe): المفتاح الأجنبي في جهة **المشاركة الإلزامية**، وتنبه إلى ذلك داخل الدرس والمختبر.
- **SQL**: المحرر يعمل على SQLite داخل المتصفح. تُترجم تلقائيًا `hr.` و `MINUS` و `NVL` و `SYSDATE`، و `LIKE` حساس لحالة الأحرف كما في Oracle. بعض خصائص Oracle (مثل `ROWNUM`) غير مدعومة.
- **BCNF** إثراء خارج الملخص، ومُعلَّم بذلك.
